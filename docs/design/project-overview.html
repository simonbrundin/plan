🤖 Agents

En personlig AI-agent harness byggd i Go, med Nuxt-frontend och PostgreSQL-persistens. Byggd för att hjälpa dig uppnå mål — steg för steg.

📖 Vad är detta?

Agents är ett system för att köra AI-agenter som hjälper dig att utföra uppgifter. Det är en harness — en ram som ger agenten rätt verktyg och kontext för att lösa problem.

Tänk på det som en arbetsbänk: Du ger agenten verktyg (läs filer, kör kommandon, skriv kod), en uppgift, och låter den jobba. Agenten använder tool calling för att interagera med omvärlden — precis som du skulle göra i en terminal.

▶️ Tre sätt att köra

💬 Interaktiv Chat

Standardläge. Starta en konversation i terminalen.

./agent

Du skriver, agenten svarar med verktyg.

🌐 HTTP Server

Startar en webb-API med Swagger-dokumentation.

./agent --serve

Frontend kan ansluta via REST + SSE.

🎯 Headless

Kör en enskild prompt utan interaktion.

./agent "din prompt här"

Bra för automation och scripts.

🔄 Dataflöde

1

Du skriver en prompt

Textraden skickas till AgentRuntime.SendMessage()

2

Agenten tänker

Prompten + konversationshistorik skickas till LLM-providern (AgentGateway → MiniMax → OpenAI)

3

Verktygsanrop

Om modellen behöver göra något (läsa fil, köra kommando) returneras ett tool_call

4

Verktyget körs

ToolExecutor anropar rätt verktyg (bash, read, write, edit, grep, glob)

5

Resultat tillbaka

Verktygsresultatet skickas tillbaka till LLM:n för nästa tanke

6

Svar till användaren

Slutresultatet visas (text, kod, filer) och sparas i databasen

pgx

PostgreSQL-persistens för conversations, messages och API keys.

Webbgränssnitt med realtidstreaming via SSE. Byggt med @nuxt/ui.

environments/prod/

🔧 Verktyg (Tools)

Verktyg Beskrivning Användning
bash Kör godtyckliga shell-kommandon Bygga, test, git, etc.
read Läs fil(er) med offset/limit Få kontext om kod, läsa dokument
read_multiple Läs flera filer samtidigt Jämföra filer, batch-läsning
write Skriv ny fil (skapar parent dirs) Skapa nya filer
edit Editera med exakt text-replacement Ändra befintlig kod
grep Regex-sökning i filer Hitta kod, funktioner, buggar
glob Filglobbing med **-stöd Hitta filer, import-statements

📝 Kommandon & Skills

Agenten har tillgång till Markdown-kommandon som ger instruktioner för specifika uppgifter:

ai-prime.md

Prime — snabb kodbasöversikt

debug-flux.md

Felsök FluxCD i Kubernetes

plan-kubernetes-debug.md

Planera Kubernetes-felsökning

Kommandon definieras i src/commands/. Skills (pi-specifika) finns i ~/.pi/agent/skills/.

🛠️ Utveckling

Starta dev-miljö

simon dev

Startar PostgreSQL + Backend via Tilt/Docker Compose

Bygga agent

cd src/agent
go build -o ../../agent ./cmd/agent

Köra tester

# Enhetstester
go test ./...

# BDD-tester
go test ./features_test/... \
  -godog.tags=@implemented

Frontend

cd src/frontend
nub run dev      # Dev server (port 3000)
nub run build    # Production build
nub run typecheck
